# Сервис обратной связи

Веб-приложение для обработки обращений пользователей с возможностью прикрепления файлов.

## 📋 Функционал
- Выбор типа обращения из выпадающего списка
- Текстовое описание проблемы
- Прикрепление файлов (до 10 МБ)
- Валидация данных на клиенте и сервере
- Возможность добавлять отзывы через API
- Тесты для приложения api и feedback


## 🚀 Как пользоваться?

### 1. Клонирование репозитория
```bash
git clone git@github.com:Sibiri4ok/impule-test-drf.git
cd impule-test-drf
```
### 2. Миграции
```bash
python manage.py makemigrations
python manage.py migrate
```

### 3. Запуск сервера
```bash
python manage.py runserver
```

### Модель FeedBackModel

| Поле             | Тип           | Описание                                                                 | Обязательное | Допустимые значения/Ограничения                     |
|-------------------|---------------|-------------------------------------------------------------------------|--------------|-----------------------------------------------------|
| feedback_type     | CharField     | Тип обращения                                                          | Да           | `suggestion` (Пожелание)<br>`problem` (Проблема)<br>`complaint` (Претензия)<br>`other` (Другое) |
| description       | TextField     | Подробное описание обращения                                           | Да           |  Нет
| attachment        | FileField     | Прикрепленный файл                                                     | Нет          | Макс. размер: 10 МБ<br>Путь сохранения: `attachments/`<br>Форматы: любые |
| created_at        | DateTimeField | Дата и время создания обращения                                        | Автоматически| Формат: `YYYY-MM-DD HH:MM:SS`     


## ➕ Добавление записей

### Способ 1: Через HTML-форму
1. Перейдите по адресу: `http://127.0.0.1:8000/`
2. Заполните поля:
   - **Тип обращения** (обязательно)
   - **Описание** (обязательно)
   - **Файл** (опционально, до 10 МБ)
3. Нажмите "Отправить обращение"

### Способ 2: Через API
**Эндпоинт:** `http://127.0.0.1:8000/api/v1/feedback/`
